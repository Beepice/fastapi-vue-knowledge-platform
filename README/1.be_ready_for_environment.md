# 环境准备手册

> 记录项目环境配置的完整步骤、前置依赖与常见问题。
> 适用于：首次克隆项目 / 换电脑 / 服务器重新部署

---

## 1. Python 环境

### 1.1 虚拟环境

#### 1.1.1 python3.12

**前置依赖**

- 操作系统已安装 Python 3.12.x（推荐 3.12.0 及以上）
- `python --version` 能正确输出版本号

#### 1.1.2 Poetry
```
**前置依赖**
- Python 3.12+ 已安装

**安装步骤**

#pip 安装:
pip install poetry

# 验证
poetry --version

#python依赖安装:
poetry install

#进入虚拟python环境:
poetry env activate
或者找到.venv中的activate.ps运行
```

**可能遇见的问题**

| 问题                                  | 原因            | 解法                                                 |
|-------------------------------------|---------------|----------------------------------------------------|
| 安装后 `poetry` 命令找不到                  | PATH 未更新      | 重启终端，或用 `python -m poetry` 调用                      |
| `poetry --version` 报错               | 旧版本 poetry 残留 | `pip uninstall poetry && pip install poetry` 重新安装  |
| Linux某些版本禁止安装poetry到系统的python3的lib中 | 避免全局环境污染      | 需要`python3 -m venv path/to/venv`建立虚拟环境后在虚拟环境安装poetry |      |

### 1.2 前端环境

#### 1.2.1 Node.js v20+

**前置依赖**

- 系统未安装 Node 或版本低于 18

**安装步骤**

```bash
# Windows：去 https://nodejs.org 下载 LTS 版本（20.x）
# 验证
node --version   # 应显示 v20.x.x
npm --version

#Linux:使用版本工具安装nodejs 20+就可以，但是对一些比较老的Ubantu，
# 软件源太老没有对应版本,需要手动更新nodejs官方软件源
curl -fssl https://deb.nodesource.com/setup_20.x

```

#### 1.2.2 knowledge-base（Vue3 项目）

**前置依赖**

- Node.js v20+ 已安装
- npm 可用

**安装步骤**

```bash
# 进入项目目录
cd knowledge-base

# 安装前端依赖
npm install

#.env注入环境变量
设置VITE_API_BASE_URL变量

# 构建生产版本（后端需要 dist/ 目录）
npm run build

# 验证 dist/ 目录已生成
ls dist/
```

**可能遇见的问题**

| 问题 | 原因 | 解法 |
|------|------|------|
| `npm install` 报 peer dependency 警告 | 依赖版本兼容警告，通常不影响运行 | 忽略，或 `npm install --legacy-peer-deps` |
| Windows 下路径斜杠问题 | `vite.config.js` 里用了 `/` | 用 `path.resolve` 拼接路径，避免硬编码 |

## 2. 数据库环境

### 2.1 Docker Compose（本地 PostgreSQL 15.4）

**前置依赖**

- Docker Desktop 已安装并运行
- Docker 镜像加速（国内服务器推荐配置）

**安装步骤**

```bash
# 启动 PostgreSQL 容器
docker-compose up -d db

# 验证容器运行
docker ps

# 确认端口映射（默认 5432）
docker port <container_id>
```

**可能遇见的问题**

| 问题 | 原因 | 解法 |
|------|------|------|
| `docker ps` 无输出 | Docker Desktop 未启动 | 右键任务栏图标 → Start，或重启 Docker 服务 |
| 端口 5432 被占用 | 系统已装其他 PostgreSQL | 修改 `docker-compose.yml` 中的端口映射：`5432:5433` |
| `docker-compose up -d` 报错 network | Docker 网络配置问题 | `docker network prune` 清理无用网络后重试 |
| 容器启动后立即退出 | 配置文件错误或权限问题 | `docker logs <container_id>` 查看具体报错 |

---

### 2.2 Linux 环境（PostgreSQL 15 + pgvector）

**前置依赖**

- Linux 服务器（Ubuntu 20.04+ 或 Debian 11+）
- 具有 sudo 或 root 权限
- 服务器内存 ≥ 1GB（推荐 ≥ 2GB）

**安装步骤**

```bash
# 1. 安装 PostgreSQL 15 + pgvector 扩展
# Ubuntu / Debian
sudo apt install -y postgresql-15 postgresql-15-pgvector

# 2. 启动服务
sudo systemctl start postgresql
sudo systemctl enable postgresql

# 3. 切换到 postgres 用户，创建数据库和用户
sudo -u postgres psql -p 5432

# 在 psql 里执行：
CREATE DATABASE your_database;
ALTER USER postgres PASSWORD 'your password';
ALTER DATABASE your_database OWNER TO postgres;
\q

# 4. 开启 pgvector 扩展（在目标数据库里）
sudo -u postgres psql -d your_database -c "CREATE EXTENSION IF NOT EXISTS vector;"

# 5. 验证
psql -U your_user -d your_database -h localhost -c "SELECT extname FROM pg_extension;"
```

**可能遇见的问题**

| 问题                                           | 原因             | 解法                                                         |
|----------------------------------------------|----------------|------------------------------------------------------------|
| `apt install` 报 `postgresql-15-pgvector` 找不到 | 仓库里没有此包名       | 分别装：`apt install postgresql-15` + 从源码装 pgvector，或用官方脚本     |
| `systemctl start postgresql` 失败              | 多版本 PG 同时存在    | 卸载多余版本（`apt remove postgresql-16 postgresql-18`），只保留 15    |
| 连接报错 `No such file`                          | PostgreSQL端口错误 | 修改 `/etc/postgresql/15/main/postgresql.conf`，设 `port=5432` |
| `CREATE EXTENSION vector` 报错不存在              | pgvector 没装上   | 确认扩展安装成功                                                   |
| 内存不足（1.58GB 服务器）                             | PG 默认配置吃内存大    | 调低 `shared_buffers`（建议 256MB）和 `max_connections`           |

## 3. 统一环境变量配置

所有环境配置完成后，需要在项目根目录创建 `.env` 文件（参考 `.env.example`）：

```bash
# 数据库连接
DATABASE_URL=postgresql://postgres:your_password@localhost:5432/your_database

# JWT 密钥（生成随机字符串，不要用默认值）
SECRET_KEY=`openssl rand -hex 32 `

# Qwen Embedding API（https://dashscope.console.aliyun.com/）
QWEN_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# FastAPI 服务
APP_ENV=dev  # dev / prod
DEBUG=True
```

> **注意**：`.env` 文件不要提交到 Git，`.gitignore` 已忽略。
> 如果需要团队共享配置，提供 `.env.example` 文件（不含真实密钥）。

## 5. 快速验证（环境是否就绪）

```bash
# 1. 数据库环境
docker ps   # 确认 postgres 容器 running
# 或
sudo systemctl status postgresql   # Linux 下确认服务 running
# 2. Python 环境
poetry --version
# 3. 前端环境
node --version   # v20.x
ls knowledge-base/dist/   # 确认有 index.html
# 4. 启动后端
poetry shell 或者进入.venv手动启动activate
alembic upgrade head   # 确认迁移成功
uvicorn app.main:app --reload

# 5. 访问
# http://localhost:8000/docs   → FastAPI 接口文档
# http://localhost:8000         → Vue3 前端页面
```
